# Hi, I'm Alireza

**M.Sc. Student in Algorithms & Computation | University of Tehran**

I'm interested in the intersection of **Graph Neural Networks (GNNs), combinatorial optimization, and machine learning**. My current focus is building a strong theoretical and practical foundation in machine learning while exploring how graph-based methods can address complex computational problems.

### Research Interests

- **Graph Neural Networks:** Learning representations of graph-structured data
- **Optimization:** Mathematical foundations and algorithms for optimization
- **Machine Learning:** Understanding learning algorithms from first principles
- **Graph Algorithms:** Theoretical foundations of graph-based computation

### Selected Projects
- [mlp-mle-map-regression](https://github.com/alirezaesfandiari80/mlp-mle-map-regression) — A comparison of maximum likelihood and maximum a posteriori estimation for neural network regression
- [Logistic Regression from Scratch](https://github.com/alirezaesfandiari80/logistic-regression-from-scratch) — An implementation of logistic regression focused on understanding its mathematical foundations and optimization process.
- [Perceptron from Scratch](https://github.com/alirezaesfandiari80/perceptron-from-scratch-) — An implementation of the perceptron learning algorithm and its underlying linear classification principles.

### Current Focus

- Strengthening my foundations in deep learning and graph machine learning
- Exploring the relationship between graph-based learning and optimization
- Developing reproducible, well-documented machine learning projects
